### VESTAr — Web3 Voting Infrastructure

Built a voting platform focused on solving trust, transparency, and scalability problems in online voting.

- Designed a smart contract-based election lifecycle
- Built private ballot flow and tally architecture
- Implemented ECDH-based key reveal flow for private ballots and transparent result verification
- Developed NestJS + Prisma + PostgreSQL backend systems
- Built blockchain event indexer for state sync and reliable data updates
- Deployed production workloads on AWS EC2 with Docker and CI/CD

- Implemented booking notifications and user activity features

- Studied fanout strategies and event-driven delivery architecture
- Focused on practical features that improve real student user flows
