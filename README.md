## Selected Work

### 🔐 30ficate — Certificate Verification Platform

Building a platform that helps users verify web certificate trust more intuitively.

#### Highlights

- Researched Certificate Transparency logs and browser certificate validation flow
- Designed certificate fingerprint verification architecture
- Explored blockchain-based trust anchoring for certificate proofs
- Planned browser extension flow for real-time certificate checking
- Focused on making complex certificate infrastructure easier to understand and use

---

### 🗳️ VESTAr — Web3 Voting Infrastructure

Built a voting platform focused on solving trust, transparency, and scalability problems in online voting.

#### Highlights

- Designed smart contract-based election lifecycle
- Built private ballot flow and tally architecture
- Implemented ECDH-based key reveal flow for private ballots
- Developed NestJS + Prisma + PostgreSQL backend systems
- Built blockchain event indexer for state synchronization
- Deployed workloads on AWS EC2 with Docker and CI/CD

---

### 🎓 CC — Campus Performance Platform

Built backend systems for a university platform that improves discovery and reservations for campus performances.

#### Highlights

- Designed AWS S3 image upload and media storage pipeline
- Implemented booking notifications and user activity features
- Explored Kafka-based asynchronous processing for scalable notifications
- Studied fanout strategies and event-driven delivery architecture
- Focused on practical features that improve real student user flows
